# 青空进学塾运营管理系统

## 更新记录（倒序）








































































### v8.5.1
- 修复从预定课时生成实际课时时 Supabase 400 报错的问题。
- 原因：v8.5 的收入结算字段误插入到了课时表单，导致保存课时时向课时表提交了不存在的字段。
- 课时保存增加字段白名单，只提交课时表允许的字段。
- 从预定生成实际课时时继续复制：
  - 开始时间
  - 结束时间
  - 时长
  - 课程单价
  - 应收课时费
- 从预定生成实际课时时，上课内容保持空白。
- 主界面版本号完整显示为 v8.5.1。
- 本版无 SQL 修改。

### v8.5
- 收入记录增加学生结算相关字段：
  - 学生结算月份
  - 实际付款币种
  - 是否计入学生月度结算
- 实际付款币种支持：
  - 人民币
  - 日元
- 学生月度结算统计已收金额时，按“学生结算月份”归属。
- 学生月度结算分别统计：
  - 已收学费（人民币）
  - 已收学费（日元）
  - 已收折算合计（人民币）
- 应补/应退计算改为使用已收折算合计人民币。
- 新增 `school_v8_5_migration.sql`，需要先执行。
- 主界面版本号完整显示为 v8.5。

### v8.4
- 新增月度结算差额计算。
- 增加“预定/实际差额（人民币）”。
- 增加“本月应补/应退/结余”。
- 计算逻辑：
  - 预定/实际差额 = 实际应收人民币 - 预定应收人民币
  - 本月最终应补/应退 = 实际应收人民币 - 已收学费人民币 - 上月结余/补交人民币
- 正数显示为应补交，负数显示为应退还/转下月结余，0 显示为已结清。
- 本版只做页面计算，不写入数据库。
- 主界面版本号完整显示为 v8.4。
- 本版无 SQL 修改。
