### v8.6.4
- 修复新增支出无法保存的问题。
- 原因：收入结算字段误混入支出表单 / 保存数据，导致向支出表提交不存在的字段。
- 移除支出与报销表单中误出现的收入专用字段：
  - 学生结算月份
  - 实际付款币种
  - 是否计入学生月度结算
- 支出保存增加字段白名单，只提交支出表允许的字段。
- 报销保存也增加字段白名单，防止同类问题。
- 主界面版本号完整显示为 v8.6.4。
- 本版无 SQL 修改。
