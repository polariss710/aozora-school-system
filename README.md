# 青空进学塾运营管理系统 v1.1

## 本版包含
- Supabase school project 连接
- 首页统计
- 业务归属管理
- 学生管理
- 老师管理
- 科目管理
- 账户管理
- 基础资料 JSON 备份导出

## 使用方法
1. 解压全部文件。
2. 用浏览器打开 `index.html`。
3. 或上传到 Netlify / Vercel / GitHub Pages 等静态托管。
4. 目前 RLS 还是开发开放状态，不建议公开部署链接。
