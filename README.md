# 青空进学塾运营管理系统

## 更新记录（倒序）














































































### v8.5.4
- 重新排查并修复课时管理右侧实际课时排序问题。
- 原因：右侧实际课时绑定在左侧预定课时行上，单独排序实际课时数组并不会改变整行顺序。
- 本版改为按“预定-实际配对行”整体排序。
- 如果右侧有实际课时，则该行按实际课时日期/时间正序排序。
- 如果右侧没有实际课时，则该行按预定课时日期/时间正序排序。
- 月度结算课时明细同步使用相同配对排序逻辑。
- 主界面版本号完整显示为 v8.5.4。
- 本版无 SQL 修改。

### v8.5.3
- 修复课时管理右侧实际课时按日期倒序显示的问题。
- 右侧实际课时现在按日期正序、开始时间正序排列。
- 月度结算课时明细右侧实际课时也同步改为正序。
- 左侧预定课时仍保留现有课程顺序排序。
- 主界面版本号完整显示为 v8.5.3。
- 本版无 SQL 修改。

### v8.5.2
- 课时管理中，预定课时日期显示为“日期 + 周”。
- 月度结算课时明细中，预定课时日期也显示为“日期 + 周”。
- 实际课时日期保持原日期显示，不追加“周”。
- 主界面版本号完整显示为 v8.5.2。
- 本版无 SQL 修改。

### v8.5.1
- 修复从预定课时生成实际课时时 Supabase 400 报错的问题。
- 原因：v8.5 的收入结算字段误插入到了课时表单，导致保存课时时向课时表提交了不存在的字段。
- 课时保存增加字段白名单，只提交课时表允许的字段。
- 从预定生成实际课时时继续复制：
  - 开始时间
  - 结束时间
  - 时长
  - 课程单价
  - 应收课时费
- 从预定生成实际课时时，上课内容保持空白。
- 主界面版本号完整显示为 v8.5.1。
- 本版无 SQL 修改。

### v8.5
- 收入记录增加学生结算相关字段：
  - 学生结算月份
  - 实际付款币种
  - 是否计入学生月度结算
- 实际付款币种支持：
  - 人民币
  - 日元
- 学生月度结算统计已收金额时，按“学生结算月份”归属。
- 学生月度结算分别统计：
  - 已收学费（人民币）
  - 已收学费（日元）
  - 已收折算合计（人民币）
- 应补/应退计算改为使用已收折算合计人民币。
- 新增 `school_v8_5_migration.sql`，需要先执行。
- 主界面版本号完整显示为 v8.5。
