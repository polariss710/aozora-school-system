## 使用方法

1. 解压全部文件。
2. 覆盖 GitHub Pages 仓库根目录文件。
3. 如 zip 中包含 `*_migration.sql`，先在 Supabase SQL Editor 执行。
4. 提交并 push。
5. 浏览器强制刷新页面。

## 注意

- 没有 SQL 修改的版本，zip 中不会包含旧 SQL 文件。
- 支出凭证上传功能需要先执行 v3.1 的 migration SQL。
