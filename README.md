## 更新记录（倒序）


















































































### v8.5.6
- 课时编辑/新增表单中，输入课程单价和时长后自动计算应收课时费。
- 点击复制课时时，课程单价和应收课时费也会一并复制。
- 预定课时日期显示改为对应上课日期所在周的周一。
- 预定课时日期显示为“周一日期 + 周”，例如 2026-05-12周。
- 日期下方副标题改为完整日期，不再只显示月份。
- 月度结算课时明细同步使用相同的周一日期显示逻辑。
- 主界面版本号完整显示为 v8.5.6。
- 本版无 SQL 修改。

### v8.5.5
- 修复从左侧某一行预定课时生成实际课时后，实际课时显示到另一行右侧的问题。
- 原因：之前为了兼容旧数据，会在 planned_lesson_id 为空时按日期/科目/老师自动匹配预定课时；当同一周有两条相似预定课时时，可能匹配到错误行。
- 本版显示逻辑改为优先并严格使用实际课时的 planned_lesson_id。
- 从哪一行点击“生成实际”，保存后就固定显示在该行右侧。
- 未带 planned_lesson_id 的旧实际课时不再强行猜测匹配，显示在未关联区域，避免错配。
- 月度结算课时明细同步使用同样的稳定关联逻辑。
- 主界面版本号完整显示为 v8.5.5。
- 本版无 SQL 修改。

### v8.5.4
- 重新排查并修复课时管理右侧实际课时排序问题。
- 原因：右侧实际课时绑定在左侧预定课时行上，单独排序实际课时数组并不会改变整行顺序。
- 本版改为按“预定-实际配对行”整体排序。
- 如果右侧有实际课时，则该行按实际课时日期/时间正序排序。
- 如果右侧没有实际课时，则该行按预定课时日期/时间正序排序。
- 月度结算课时明细同步使用相同配对排序逻辑。
- 主界面版本号完整显示为 v8.5.4。
- 本版无 SQL 修改。
