# 青空进学塾运营管理系统

## 更新记录（倒序）


































































































### v8.7
- 新增学生月度结算确认 / 锁定功能。
- 新增结算锁定表 `school_student_monthly_settlements`。
- 月度结算页面增加“结算确认 / 锁定”区域。
- 支持三种差额处理方式：
  - 结转到下月
  - 抹平差额
  - 手动调整
- 系统计算差额：实际应收人民币 - 已收折算人民币 - 上月结转。
- 调整后结转：系统计算差额 + 调整金额。
- 支持保存预定课时费、实际课时费、已收金额、系统差额、调整金额、调整原因、下月结转金额和锁定时间。
- 新增 `school_v8_7_migration.sql`，需要先执行。
- 主界面版本号完整显示为 v8.7。

### v8.6.4
- 修复新增支出无法保存的问题。
- 原因：收入结算字段误混入支出表单 / 保存数据，导致向支出表提交不存在的字段。
- 移除支出与报销表单中误出现的收入专用字段：
  - 学生结算月份
  - 实际付款币种
  - 是否计入学生月度结算
- 支出保存增加字段白名单，只提交支出表允许的字段。
- 报销保存也增加字段白名单，防止同类问题。
- 主界面版本号完整显示为 v8.6.4。
- 本版无 SQL 修改。
